# Paradise Nursery 🌿

A React-based e-commerce plant shop application built with Redux Toolkit for state management.

## Project Name
**Paradise Nursery** — Your one-stop destination for beautiful houseplants, succulents, and garden essentials.

## Features
- Browse a curated product listing of plants
- Add/remove items to shopping cart
- Update item quantities in cart
- View cart total and item count
- Responsive design with a nature-inspired aesthetic

## Tech Stack
- React 18
- Redux Toolkit (RTK)
- React Redux
- CSS3

## Getting Started

\`\`\`bash
npm install
npm start
\`\`\`
